# Gaurav Nursery v2 UI reference

The supplied marketplace board is the approved visual direction for v2. It defines the product layout and navigation density; it is not a static mockup to be embedded in the product.

## Shared visual language

- Customer web: white and forest-green header, compact search, category menu, editorial plant imagery, small product cards, and green action buttons.
- Seller panel: charcoal left sidebar, orange accent, high-density operational tables, inventory/order status chips, and light chart cards.
- Admin panel: charcoal left sidebar, royal-blue accent, moderation/finance tables, KPI cards, approval queues, and analytics charts.
- All panels: responsive shell, consistent table/filter/pagination patterns, empty/loading/error states, and accessible focus states.
